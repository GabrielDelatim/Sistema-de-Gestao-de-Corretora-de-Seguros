# Sistema-de-Gestao-de-Corretora-de-Seguros
aplicação web em Flask que centraliza o cadastro de clientes, apólices, sinistros e cartões; inclui controle de acesso baseado em papéis (admin, comercial, assistente, sinistros), fluxo de trabalho Kanban para seguros e sinistros, e boas práticas de segurança (criptografia de senhas, .gitignore rigoroso, logs de auditoria).
